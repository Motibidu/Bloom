# 사진 탭 신설 — 설계 문서

작성일: 2026-07-30

## 배경

현재 피드 탭(`FeedPage.tsx` + `CheckInCard`)은 아바타/닉네임 헤더 → 본문 텍스트 → 사진(선택) → 반응 바 순서의 전통적 카드 레이아웃이다. 사용자가 원하는 스타일은 사진이 카드 전체 배경을 채우고 제목·작성자·좋아요/댓글 수·날짜가 사진 위에 오버레이되는 Pinterest/Instagram형 그리드다.

이 스타일은 사진이 있는 게시물에만 자연스럽다. 논의 끝에 다음으로 스코프가 정해졌다:

- 기존 "전체 피드"는 그대로 둔다 (텍스트 카드 스타일 유지, 변경 없음).
- 하단 탭바의 **"찾기" 탭을 "사진" 탭으로 교체**한다.
- "찾기"(사람 검색/팔로잉/팔로워)는 **"나의활동"(마이페이지) 내부로 이동**한다.
- 사진 탭에 사진 없는 체크인이 섞이지 않도록, **상세 기록 작성 시 사진을 필수**로 만든다. 이렇게 하면 별도의 "사진 유무" 서버 필터링 로직이 필요 없다 (간편 기록은 애초에 가족 탭 전용이라 이 정책과 무관).

## 승인된 시안

`/preview`로 확인 완료 (사용자 승인됨). 카드 사양:

- `aspectRatio: 4/5`, `rounded-2xl`, `boxShadow: 0 2px 16px mA(0.12)`
- 사진 `object-cover`로 카드 전체 채움
- 하단 60~65% 높이에 `linear-gradient(to top, oklch(0 0 0/0.75), oklch(0 0 0/0.25) 55%, transparent)` 오버레이
- 우상단 날짜 뱃지: `oklch(0 0 0/0.35)` 배경 + `backdrop-blur`
- 하단 텍스트: 제목(`font-black`, 1줄 clamp) → 닉네임 + 좋아요/댓글 아이콘 카운트 한 줄
- 모바일 2열 그리드, 데스크탑 4열 그리드, 그리드 gap 8px(모바일)/16px(데스크탑)

## 변경 범위

### 1. 사진 탭 (신규)

- **라우트**: 기존 `/discover` 경로와 `DiscoverPage` 컴포넌트를 사진 탭으로 교체. (경로명은 구현 단계에서 `/photos` 등으로 변경 검토 — URL이 사용자에게 노출되는 요소가 아니므로 자유도 있음)
- **데이터 소스**: `useInfiniteTodayFeed`와 동일한 무한스크롤 커서 패턴을 사진 전용으로 재사용. 상세 기록에 사진이 필수가 되므로, `isSimple=false`인 체크인은 항상 사진을 갖는다. 백엔드 쿼리 수정 불필요 — 기존 `/checkins/today` 응답에서 `isSimple=false && photoUrls.length>0`인 항목만 클라이언트에서 사용(사실상 전부 해당).
  - 단, 사진 필수화 이전에 작성된 기존 상세 기록 중 사진이 없는 레코드가 있을 수 있음 → 프론트에서 `photoUrls.length > 0` 가드 유지.
- **새 컴포넌트**: `PhotoFeedCard` (`src/components/ui/domain/checkin/photo-feed-card.tsx`) — 시안대로 구현. 클릭 시 기존 `ActivityDetailPage`로 이동(상세 진입 시에만 본문 노출).
- **새 페이지**: `PhotoFeedPage` (`src/pages/PhotoFeedPage.tsx`) — 그리드 레이아웃 + 무한스크롤 sentinel. `FeedPage.tsx`의 IntersectionObserver/스크롤 복원 패턴 재사용.
- **BottomTabBar**: "찾기"(Search 아이콘) → "사진"(Image/Camera 아이콘)으로 라벨·아이콘·경로 교체.

### 2. 찾기 기능 이동

- `DiscoverPage`의 사람 검색/팔로잉/팔로워 탭 콘텐츠는 그대로 재사용하되, 진입 경로를 `MyActivityPage` 헤더의 액션 버튼 그룹(현재 편집/월간리포트/차단목록 아이콘 3개가 있는 자리)에 검색 아이콘 버튼을 추가해 `/discover` 경로로 이동시키는 방식으로 연결한다.
- `DiscoverPage` 자체와 라우트(`/discover`)는 유지하되, 하단 탭바에서는 더 이상 노출되지 않음.

### 3. 상세 기록 사진 필수화

- `CheckinWritePage.tsx`의 상세 모드(`mode === 'detail'`):
  - "사진 첨부" 섹션 라벨을 `(선택, 최대 3장)` → `(필수, 최대 3장)`으로 변경.
  - `canSubmitDetail` 조건에 `photoFiles.length > 0` 추가.
  - 사진 미첨부 시 안내 문구 노출 (기존 "카테고리를 선택해 주세요" 톤과 동일하게).
- 간편 모드는 변경 없음 (사진 필수 아님, 가족 탭 전용 유지).

## 비범위 (이번 작업에서 하지 않음)

- 백엔드 API/쿼리 변경 없음 (사진 필터링을 위한 신규 파라미터 불필요).
- 기존 "전체 피드"/"팔로우 피드" 텍스트 카드 스타일 변경 없음.
- 사진 탭 자체 내 "팔로우만 보기" 등 필터는 이번 스코프에 포함하지 않음 (전체 공개 피드 기준, 기존 피드와 동일한 공개 정책 적용).

## 오픈 이슈 / 리스크

- 사진 필수화 이전 작성된 사진 없는 상세 기록이 사진 탭에서 자동 제외됨 — 데이터 손실은 아니고 전체 피드에서는 계속 보임.
- `/discover` 진입점이 하단 탭바에서 사라지므로 마이페이지 액션 버튼이 4개로 늘어남 — 아이콘 전용 버튼이라 공간은 확보되나 시각적 밀도 증가. 필요 시 `MoreHorizontal` 메뉴로 묶는 것을 구현 단계에서 검토.
