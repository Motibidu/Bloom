## 슈미토 클럽 벤치마크 기반 한국형 커뮤니티+이벤트 설계

**작성일**: 2026-05-18  
**참조**: `docs/bloom-research-synthesis.md`  
**포지셔닝**: 슈미토 클럽의 "취미 그룹 + 오프라인 이벤트"에 대응하는 한국형 메인 기능

---

## 설계 전제

### 왜 일기/사진이 메인이 아닌가

일기와 사진 업로드는 **진입 허들을 낮추는 유입 수단**이다. 사용자가 처음 Bloom에 들어왔을 때 "뭔가 해볼 수 있겠다"는 첫 성공 경험을 주기 위한 장치.

진짜 메인 기능은 사용자가 **매일 앱을 열어야 할 이유** — 즉 나와 연결된 사람들과의 관계다.

### 슈미토 클럽과의 구조적 차이

| 항목 | 슈미토 클럽 | Bloom 모임방 |
|---|---|---|
| 연결 기반 | 취미 (낯선 사람) | 관계 (아는 사람) |
| 진입 방식 | 누구나 오픈 가입 | 초대 코드 전용 |
| 그룹 규모 | 대형 (수백~수천명) | 소규모 (최대 50명) |
| SNS 목적 | "나는 이런 사람이야" 정체성 선언 | "나는 아직 이런 사람이야" 현역성 입증 |
| 오프라인 전환 | 취미 클럽 정기 모임 | 아는 사람끼리 번개 약속 |

슈미토 클럽이 **"취미가 정체성이다"** 라면, Bloom은 **"오늘 하루가 정체성이다"**

## 메인 기능 1: 모임방

### 개요

동창, 동네 이웃, 관심사 기반으로 **이미 아는 사람들끼리 소규모 공간**을 만들어 서로의 일상을 공유하는 핵심 커뮤니티 기능.

슈미토 클럽의 "취미 그룹"과 구조는 유사하지만, **초대 코드 전용 진입**으로 낯선 사람에 대한 한국 중장년의 심리적 장벽을 해소한다.

### 모임방 유형 3가지

| 유형 | 아이콘 | 예시 | 특성 |
|---|---|---|---|
| 동창방 | 🎓 | "OO고 82학번 모임" | 학연 기반, 강한 재연결 욕구 |
| 동네 이웃방 | 🏘️ | "강남구 잠원동 이웃" | 지연 기반, 일상 공유 |
| 관심사방 | 🌱 | "텃밭 가꾸는 사람들" | 취미 기반, 느슨한 연결 |

## 메인 기능 2: 오늘의 활동 요약 카드

### 개요

모임방 피드 상단에 항상 고정되는 한 줄 요약. **"나만 안 하고 있다"는 FOMO**와 **"나도 활동 중인 사람이다"는 현역성 입증** 트리거를 동시에 자극.

### 디자인

```
┌────────────────────────────────────────┐
│  🔥 오늘 23명 중 8명이 활동했어요      │
│     나도 기록하러 가기 →               │
└────────────────────────────────────────┘
```

- 활동 인원이 절반 이상이면: "오늘 다들 활발하네요!"
- 활동 인원이 적으면: "오늘 첫 번째 기록을 남겨보세요"
- 내가 이미 기록했으면: "오늘 기록 완료 ✓ 멤버들 소식 확인해보세요"

### 내부 트리거 연결

| 상황 | 감정 트리거 | 문구 |
|---|---|---|
| 아직 기록 안 함 + 멤버 다수 기록 | FOMO + 소속감 결핍 | "오늘 8명이 활동했어요. 나도 한마디 남겨볼까요?" |
| 내가 기록함 | 현역성 입증 + 인정 욕구 | "오늘 기록 완료! 멤버들 응원해주세요 ♡" |
| 모두 기록 없음 | 영감 자극 | "오늘 첫 번째 기록을 남겨보세요" |

## 메인 기능 3: 함께하기 제안 (번개 약속)

### 개요

공식 이벤트가 아닌 **가벼운 번개 약속 제안** 기능. 슈미토 클럽의 오프라인 이벤트에 대응하지만, 낯선 사람 경계심이 강한 한국 중장년 특성을 반영해 **아는 사람끼리만** 제안 가능.

## 데이터 모델

### 신규 엔티티

```
Gathering (모임방)
├── id: Long
├── name: String
├── type: Enum (ALUMNI, NEIGHBOR, INTEREST)
├── description: String
├── inviteCode: String (7일 유효)
├── maxMembers: Int (기본 50)
├── createdBy: User
└── createdAt: LocalDateTime

GatheringMember (모임방 멤버)
├── id: Long
├── gathering: Gathering
├── user: User
├── role: Enum (OWNER, MEMBER)
└── joinedAt: LocalDateTime

GatheringPost (모임방 게시글)
├── id: Long
├── gathering: Gathering
├── author: User
├── checkin: Checkin (nullable, 체크인 연동)
├── content: String
└── createdAt: LocalDateTime

GatheringEvent (함께하기 제안)
├── id: Long
├── gathering: Gathering
├── title: String
├── scheduledAt: LocalDateTime
├── location: String
├── maxParticipants: Int
└── createdBy: User

GatheringEventParticipant (참여자)
├── id: Long
├── event: GatheringEvent
└── user: User
```

### 기존 도메인 연동

- `GatheringPost`는 기존 `Checkin`과 연결 가능 — 체크인 등록 시 "이 기록을 모임방에도 공유할까요?" 옵션
- 기존 `like`, `comment` 도메인을 `GatheringPost`에도 적용 (다형성 or 별도 테이블)

## 내부 트리거 매핑

| 트리거 | 강도 | 모임방 연결 지점 |
|---|---|---|
| 현역성 입증 | ★★★★★ | "오늘 8명 중 5명이 활동" 요약 카드 |
| 가족 연결 | ★★★★★ | 가족방 유형 → 자녀에게 "부모님 오늘 활동" 알림 |
| 오래된 관계 재연결 | ★★★★ | 동창방 유형 → 초대 코드로 옛 동창과 재연결 |
| 즉각적 감정 교환 | ★★★★ | 모임방 내 리액션 5종 + 칭찬 카드 |
| 소속감 결핍 | ★★★★ | 나와 비슷한 사람들의 일상 공유 |

## 슈미토 클럽과의 차별화 포인트

| 항목 | 슈미토 클럽 | Bloom |
|---|---|---|
| 진입 장벽 | 누구나 검색/가입 | 초대 코드 전용 → 안전한 관계망 |
| 규모 | 대형 (익명성) | 소규모 (친밀감) |
| 오프라인 전환 | 취미 클럽 정기 모임 | 번개 약속 (부담 없는 첫 만남) |
| 가족 연결 | 없음 | 가족방 → 자녀와 연결 경로 |
| 체면 보호 | 고려 없음 | 초대 코드 + 소규모로 체면 보호 |

## UX 원칙 (50~60대 적용)

- **초대 코드는 숫자+영문 6자리** — "BLOOM-8K2X" 형식, 타이핑 쉽게
- **카카오톡 공유 우선** — 50~60대가 가장 익숙한 공유 채널
- **모임방 이름은 자동 제안** — "OO지역 이웃방", "OO학교 OO학번" 템플릿
- **최대 인원 기본값 50명** — 소규모 친밀감 유지
- **함께하기 제안은 1주일 이내만** — 너무 먼 미래 계획은 부담
