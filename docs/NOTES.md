## UX / 기능 개선

### "나와 같은 N명" 배너 관련

- **같은 활동 확인 불가**: 배너를 통해 같은 카테고리를 기록한 사용자 목록은 볼 수 있지만, 그 사람이 오늘 어떤 활동을 했는지(제목, 내용)는 확인할 수 없음. 해당 사용자의 체크인 상세를 볼 수 있는 링크 또는 미리보기 추가 필요.

- **간편 체크인 숨김 문제**: 같은 카테고리를 기록했더라도 간편 체크인(`is_simple = true`)으로 등록한 경우 피드에서 노출되지 않아, 배너에는 카운트되지만 피드에서는 해당 사람의 기록을 찾을 수 없는 불일치 발생. 간편 체크인 노출 정책 재검토 또는 배너 카운트 기준 통일 필요.
