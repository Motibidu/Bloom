# PRD: 오늘 뭐 했어요?

> 50~60대 중장년층을 위한 일상 활동 기록 및 소셜 연결 서비스  
> 프로덕션: https://pcgear.store

---

## 서비스 한 줄 정의

하루에 한 가지 활동을 기록하고, 같은 활동을 한 이웃과 공감을 나누거나 가족에게 안부를 전하는 중장년층 전용 소셜 서비스.

---

## 핵심 사용자

| 역할 | 대상 | 가입 조건 |
|---|---|---|
| `MEMBER` | 50~60대 본인 | 출생연도 ≤ 1976 (만 49세 이상) |
| `FAMILY_VIEWER` | 자녀 등 가족 | 초대 코드 지참 (나이 무관) |

- MEMBER: 모든 기능 사용 가능
- FAMILY_VIEWER: 가족 피드 열람 + 마이페이지만. 공개 피드 작성 불가

---

## 배포 환경

- **웹**: 반응형 브라우저
- **앱**: 동일 웹을 React Native WebView로 감싼 iOS/Android 앱
- **알림 이중 구조**: 웹 → SSE 실시간 알림 / 앱 → FCM 푸시 알림
- **프로덕션 서버**: OCI Ubuntu, Docker Compose (`bloom-frontend-1`, `bloom-backend-1`, `bloom-mysql-1`)
- **CI/CD**: master 브랜치 push → GitHub Actions → 자동 배포

## 기능 목록

### 1. 인증

- 이메일 + 비밀번호 회원가입 (3단계: 약관 동의 → 계정 정보 → 프로필)
- 이메일 인증 (회원가입 시 인증 메일 발송)
- 카카오 로그인 / 온보딩 (카카오 계정으로 최초 로그인 시 닉네임·나이 입력)
- JWT 인증 (Access Token + Refresh Token Rotation)
- 로그아웃

### 2. 활동 기록 (체크인)

두 가지 기록 방식:

| 구분 | 방법 | 공개 피드 노출 | 가족 탭 노출 |
|---|---|---|---|
| 상세 기록 | 제목 + 본문 + 사진(최대 3장) | ✅ | ✅ |
| 간편 기록 | 카테고리 선택 → "산책했어요" 자동 생성 | ❌ | ✅ |

**이유**: "산책했어요" 한 줄은 모르는 이웃에겐 소음이지만 자녀에겐 안부다.  
→ ADR-001 참조

카테고리 7종: 산책, 요리, 독서, 정원 가꾸기, 운동, 친구 만남, 기타

### 3. 공개 피드

- 오늘의 활동 피드 (상세 기록만 노출, 무한 스크롤)
- 인라인 활동 작성 (피드 상단에서 바로 기록)
- 같은 카테고리 참여자 수 표시 ("오늘 산책한 이웃 14명")
- 5종 반응 (좋아요 외 이모지 반응)
- 댓글 + 대댓글
- 칭찬카드 (별도 반응 카드 형식)
- 카카오톡 / 네이버 밴드 공유
- OG 메타태그 (링크 미리보기)

### 4. 가족 그룹

- 가족 그룹 생성 (1인 1그룹)
- 초대 코드 발급 + 카카오톡 공유
- 초대 코드로 가입 → FAMILY_VIEWER 역할 자동 부여 + 그룹 GUEST 등록
- 가족 전용 피드 (간편 기록 + 상세 기록 모두 노출)
- 가족 프롬프트: 가족 구성원에게 "오늘 뭐 했어요?" 알림 발송
  - 템플릿 선택 or 직접 입력
  - 응답(RESPONDED) / 무시(DISMISSED) 처리
  - 배너에 수신 프롬프트 표시 → 기록 완성 시 자동 연결
- 그룹 탈퇴

### 5. 사용자 탐색 & 소셜

- 사용자 검색 (닉네임)
- 팔로우 / 언팔로우
- 팔로잉 / 팔로워 목록
- 차단 / 차단 해제 / 차단 목록
- 신고

### 6. 나의 활동

- 월별 캘린더 (날짜별 활동 표시)
- 날짜별 체크인 목록
- 카테고리별 통계

### 7. 월간 리포트

- 이달의 활동 통계
- 전월 대비 비교 데이터
- 캘린더 뷰

### 8. 프로필

- 프로필 이미지 업로드 (S3)
- 닉네임 / 자기소개 수정
- 닉네임 중복 확인

### 9. 알림

- 실시간 알림 조회 (SSE — 웹)
- FCM 푸시 알림 (앱)
- 알림 읽음 처리
- 알림 종류: 좋아요, 댓글, 팔로우, 가족 프롬프트 등

### 10. 법적 / 기타

- 서비스 이용약관
- 개인정보 처리방침
- 공유 미리보기 페이지 (카카오톡 링크 수신자용)
- 가족 초대 랜딩 페이지 (초대 코드 미보유자 안내)

## 핵심 설계 결정

### 공개 피드 vs 가족 탭 분리

| 탭 | 소비자 | 노출 콘텐츠 | 가치 |
|---|---|---|---|
| 공개 피드 | 모르는 이웃 | 상세 기록만 | 공감·교류 |
| 가족 탭 | 자녀 | 간편 + 상세 기록 | 안부 확인 |

→ ADR-001 참조

### 나이 제한

공개 피드는 50~60대 콘텐츠로만 채워야 서비스 정체성 유지.  
자녀는 초대 코드로 FAMILY_VIEWER 가입 허용 (공개 피드 작성 불가).

→ ADR-002 참조
