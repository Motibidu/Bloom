## 프로젝트 개요

50~60대 중장년층을 위한 일상 활동 기록 및 소셜 연결 서비스. Spring Boot 백엔드와 React 프론트엔드 모노레포.

## 기술 스택

### 프론트엔드
React 19 / TypeScript / Vite / TailwindCSS 4 / React Router v7 / Zustand / TanStack Query / Axios / React Hook Form / ShadcnUI

### 백엔드
Spring Boot 3.4 / Java 21 / Spring Security / Spring Data JPA / MySQL / AWS S3 / JJWT 0.12 / SpringDoc OpenAPI (Swagger UI: `http://localhost:8080/swagger-ui.html`) / Lombok
