## 프로젝트 개요

JWT 인증이 구현된 풀스택 스타터킷 모노레포. Spring Boot 백엔드와 React 프론트엔드로 구성.

## 기술 스택

### 프론트엔드
React 19 / TypeScript / Vite / TailwindCSS 4 / React Router v7 / Zustand / TanStack Query / Axios / React Hook Form / ShadcnUI

### 백엔드
Spring Boot 3.4 / Java 21 / Spring Security / Spring Data JPA / MySQL / JJWT 0.12 / SpringDoc OpenAPI (Swagger UI: `http://localhost:8080/swagger-ui.html`) / Lombok
